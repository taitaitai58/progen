# 動物タワーバトル 🐾

pymunkとpygameを使用した物理エンジンゲームです。動物を積み上げてタワーを作り、物理演算を楽しむゲームです。

## 🎮 ゲームの遊び方

1. **動物を配置**: 画面をクリックすると、選択中の動物が配置されます
2. **動物を切り替え**: キーボードの `1` ～ `5` キーで動物の種類を切り替えられます
3. **非凸物体モード**: `M` キーで非凸物体モードに切り替え、複雑な形状を配置できます
4. **カスタムメッシュ**: `Ctrl+L` でエディターで作成したメッシュを読み込めます
5. **リセット**: `R` キーで全てのオブジェクトを削除してリセットできます

### 動物の種類

- **1: cat** (猫) - オレンジ色、標準の重さ
- **2: dog** (犬) - 黄色、やや重い
- **3: rabbit** (うさぎ) - 白色、軽い
- **4: bear** (クマ) - 茶色、とても重い
- **5: bird** (鳥) - 青色、とても軽い

## 🚀 セットアップ方法

### 必要なもの

- Python 3.8以上
- pip（Pythonパッケージマネージャー）

### インストール手順

1. **リポジトリをクローンまたはダウンロード**
   ```bash
   git clone <リポジトリのURL>
   cd progen
   ```

2. **仮想環境を作成（推奨）**
   
   **Windows:**
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```
   
   **Mac/Linux:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **依存パッケージをインストール**
   ```bash
   pip install -r requirements.txt
   ```

4. **ゲームを実行**
   ```bash
   python main.py
   ```

## 🎨 メッシュエディター

画像に形状を配置して非凸メッシュを作成できるエディター機能があります。

### エディターの起動

```bash
python editor_main.py [画像パス]
```

例:
```bash
python editor_main.py images/animal.png
```

**注意**: 画像ファイルはPNG、JPG、BMPなどの形式に対応しています。画像がない場合は、エディターを起動してから背景なしで形状を配置することもできます。

### エディターの使い方

1. **画像を読み込む**: コマンドライン引数で画像パスを指定
2. **形状を配置**: 
   - `P` キーで配置モードに切り替え
   - 画面をクリックして形状を配置
   - `1` キー: 三角形、`2` キー: 円、`3` キー: 矩形
3. **ポリゴン描画（線分で輪郭を描く）**:
   - `W` キーでポリゴン描画モードに切り替え
   - 画像上をクリックして点を配置（線分で輪郭を描く）
   - `Enter` または `Space` キーで完成（自動で三角分割）
   - 最初の点の近くをクリックしても閉じる
   - `Esc` キーでキャンセル
4. **形状を編集**:
   - `D` キー: 削除モード（形状をクリックで削除）
   - `M` キー: 移動モード（形状をドラッグで移動）
   - `+/-` キー: サイズ調整
   - `C` キー: 色の切り替え
5. **保存/読み込み**:
   - `Ctrl+S`: メッシュを保存（mesh.json）
   - `Ctrl+O`: メッシュを読み込み
6. **その他**:
   - `R` キー: 全削除

### ゲームでカスタムメッシュを使用

1. エディターでメッシュを作成して保存
2. ゲーム中に `Ctrl+L` でメッシュを読み込み
3. 非凸物体モードで、読み込んだメッシュを選択して配置

## 🛠️ 開発に参加する方へ

### コードの構造

- **config.py**: ゲームの設定（画面サイズ、色、物理パラメータなど）を管理
- **animals.py**: 動物クラスと動物の種類を定義
- **game.py**: ゲームのメインロジック（イベント処理、描画、物理更新）
- **main.py**: プログラムのエントリーポイント

### カスタマイズのヒント

- **新しい動物を追加**: `animals.py` の `ANIMALS` 辞書に新しいエントリを追加
- **色を変更**: `config.py` で色を定義し、`animals.py` で使用
- **物理パラメータを調整**: `config.py` の `GRAVITY`、`ANIMAL_MASS` などを変更
- **画面サイズを変更**: `config.py` の `SCREEN_WIDTH` と `SCREEN_HEIGHT` を変更
