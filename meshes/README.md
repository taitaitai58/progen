# メッシュフォルダ

このフォルダにメッシュを配置してください。

## フォルダ構造

```
meshes/
├── mesh1/
│   ├── mesh.json
│   └── texture.png
├── mesh2/
│   ├── mesh.json
│   └── texture.png
...
```

## 使い方

1. メッシュエディターでポリゴンを描いて`mesh.json`を保存
2. 各メッシュ用のフォルダを作成（例：`mesh1/`）
3. `mesh.json`と画像ファイルをそのフォルダに配置
4. ゲーム起動時に自動で読み込まれます

## 注意

- フォルダ名がメッシュ名として使用されます
- `mesh.json`は必須です
- 画像ファイルは任意ですが、推奨されます（.png, .jpg, .jpeg, .bmp対応）
